# Smart Movie Ticket Booking System

This project is a modified version of an existing open-source movie ticket booking project.

## Technologies
- HTML
- CSS
- JavaScript
- Local Storage

## Original functionality
- Movie selection
- Seat selection
- Sold seats
- Ticket price calculation
- Local storage

## Added features
1. Bulk ticket discount
   - 1-2 tickets: no discount
   - 3-4 tickets: 5% discount
   - 5 or more tickets: 10% discount
2. Movie search and category filter
3. Dark/Light mode
4. Booking confirmation message

## How to run
Open `index.html` in a web browser.
